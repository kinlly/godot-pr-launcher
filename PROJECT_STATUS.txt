================================================================================
  NEXT STEPS ON WINDOWS (ALLY ROX)
================================================================================

1. Install Prerequisites:
   - Rust: winget install Rustlang.Rust.MSVC
   - Node.js: winget install OpenJS.NodeJS.LTS
   - Visual C++ Build Tools

2. Clone and Setup:
   git clone https://github.com/kinlly/godot-pr-launcher.git
   cd godot-pr-launcher
   git checkout copilot/create-desktop-app-using-tauri
   npm install

3. Run in Development:
   npm run tauri dev

4. Build for Production:
   npm run tauri build
   
   Output: src-tauri/target/release/godot-pr-launcher.exe

5. Use the App:
   - Double-click the .exe
   - View PRs from kinlly/ylbtm
   - Click any PR to launch Godot

Key Features:

  - Async PR fetching with error handling
  - Process spawning for Godot launcher
  - Modern gradient UI with hover effects
  - Loading states and error display
